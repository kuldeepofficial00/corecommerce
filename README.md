# 📦 CoreCommerce — Headless B2B E-Commerce & Warehouse Inventory Engine

Enterprise B2B headless e-commerce and real-time inventory allocation engine.

## API Reference
- `GET /api/v1/products` - Catalog list with wholesale pricing tiers
- `POST /api/v1/inventory/adjust` - Atomic stock level adjustments
- `POST /api/v1/orders` - B2B wholesale order allocation
- `POST /api/v1/fulfillment/waves` - Wave-picking optimization
